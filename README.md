# 子网计算器（Subnet Calculator）

一个单文件的 IP 子网计算工具，本地内存占用仅150KB,运行速度极快，全部逻辑（HTML / CSS / JavaScript）内联在一个 `subnet-calculator.html` 中，无任何第三方依赖，双击或直接在浏览器打开即可使用，也可下载后离线使用。
支持直接访问在线网站使用，在线网站地址：https://ipsub-for-xiaochen.gicp.fun/

## 功能

### IPv4 计算器
- 掩码滑杆 / 点分十进制 / CIDR 三种掩码表示联动
- 网络号、第一可用 IP、最后可用 IP、广播地址、通配符、地址范围
- 子网划分：按需划分 1 ~ 512 个子网，明细含每块网络地址 / 起始 / 结束 / 广播地址

### IPv6 计算器
- 支持完整 / 压缩（`::`）/ 内嵌 IPv4 写法，前缀 0 ~ 128
- 网络号、IP 地址范围、地址类型（全球单播、链路本地、ULA、组播等）
- 子网划分：1 ~ 512 个子网，按 RFC 4291 / RFC 6164 处理边界前缀

### 智能模式（IPv4 / IPv6 可切换）
- **智能聚合**：输入一堆零散网段，输出三种聚合方案
  - IPv4：精细化聚合 / 最小覆盖聚合 / 有类聚合
  - IPv6：精细化聚合 / 最小覆盖聚合 / 半字节（nibble）聚合
  - 点击任意网段标签可查看详情（掩码、地址总数、起止地址、类型），`Ctrl + 点击` 直接复制
- **智能子网（VLSM）**：输入「部门 + 主机数」需求清单，自动按需求量切块并连续分配
  - IPv4 支持切换分配顺序（大 → 小 / 输入顺序 / 小 → 大）
  - IPv6 支持「/64 惯例」（SLAAC）与「按需细分」（最细 /128）两种粒度

### 其它
- 中文标点自动转半角、`/` 跳格、整段粘贴拆分、输入法组字期间不打断
- 一键下载当前页面为干净的 HTML 文件（自动复位到初始状态）
- 桌面 / 平板 / 手机端响应式布局

## 使用

直接用浏览器打开 `subnet-calculator.html` 即可，无网络环境同样可用。
